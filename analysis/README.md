表3・4の割合は、各測定の未丸めの入出力電力差を分母に計算する。loss_shares.jsonに電力と割合を保存。本文では採番を使わず、入出力条件で記す。強化学習に関する記述は実測からの適用案であり、学習実施済みの結果ではない。

研究目的の訂正：自動車の回生ブレーキの減速度制御に強化学習を用いる。入力は初期約60Vから低下、維持する電流は2～3A。低電圧・小電力で学習を試せるかという以前の評価は撤回し、現在のL1を用いた構成の直接採用は難しいという評価へ訂正。最新のユーザー訂正により、2～3Aはモータからコンバータへの入力側回生電流。EDLC充電電流ではない。入力60V時は入力電力120～180W。連続電流近似はIL平均≒Iin/Dを使用し、EDLC電流を基準にした計算は採用しない。
